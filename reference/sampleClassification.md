# Assign a signature-specific classification to each sample

This function assigns a signature-specific classification to each sample
using the mixture model of normal distributions. In the mixture model,
the sub-distribution with the lower mean value is designated as the
alternative distribution. The function applies a hypothesis-testing
approach where the null hypothesis posits that a sample belongs to this
alternative distribution. Samples that successfully reject the null
hypothesis are assigned to the signature classification. By contrast,
samples that fail to reject the null hypothesis remain unclassified. The
null hypothesis is rejected when the probability of the samples being
part of the alternative distribution is inferior to 0.05.

## Usage

``` r
sampleClassification(geneLists, gsvaRes, modelMix)
```

## Arguments

- geneLists:

  a `list` containing signature gene lists.

- gsvaRes:

  a `matrix` as generated by the GSVA function. The `matrix` should
  contain the GSVA score for all the samples (column) and the signatures
  (row).

- modelMix:

  a `list` containing one entry for each gene signature present in the
  `geneLists` object. Each entry contains the mixtures of two normal
  distributions for the signature calculated with sampled values. The
  entry corresponds to the object returned by the
  \`mixtools::normalmixEM\` function.

## Value

a `list` containing one entry for each gene signature present in the
`geneLists` object. Each entry contains the signature-specific
classification assigned to each sample. When the sample is not assigned
to the signature, the `unclassified` value is present. Conversely, the
name of the signature is present when the sample is assigned to the
signature. When the mixture of normal distributions has not been
calculated successfully, the `NA` value is returned.

## Examples

``` r

## Required library
library(GSVA)

## Load signatures
data(signaturesDemo)

## Create a list of two signatures
geneLists <- list()
geneLists[["classical"]] <- 
    signaturesDemo$`Classical`
geneLists[["basal"]] <- 
    signaturesDemo$`Basal-like`

## Load demo normalized expected counts
data(expNormalCountsDemo)

gsvaParameter <- gsvaParam(exprData=as.matrix(expNormalCountsDemo),
    geneSets=geneLists)
resClass <- gsva(param=gsvaParameter, verbose=FALSE)

## Calculate standard deviation for each sample using the permutation method
permResult <- splitTypeR:::permuteGSVA(geneLists=geneLists, 
    countMatrix=expNormalCountsDemo, permRatio=0.75, permNbr=20)

## Draw 10 values from the normal distribution for each sample (upscaling)
normResult <- splitTypeR:::extractFromNormalDist(geneLists=geneLists, 
    gsvaRes=resClass, gsvaSD=permResult$SD, nbValues=10)

## Obtain the mixtures of normal distributions for each signature
model <- splitTypeR:::normalMix(geneLists=geneLists, resultNorm=normResult)

## Obtain the assignment of each sample for each signature
result <- splitTypeR:::sampleClassification(geneLists=geneLists, 
    gsvaRes=resClass, modelMix=model)
    
## Assignment for the classical signature
head(result$classical)
#>           GSVA_score classification
#> Patient_1  0.1422663   unclassified
#> Patient_2  0.4274225      classical
#> Patient_3 -0.7532768   unclassified
#> Patient_4  0.3479971      classical
#> Patient_5 -0.6732937   unclassified
#> Patient_6  0.5735090      classical
## Assignment for the basal signature
head(result$basal)
#>           GSVA_score classification
#> Patient_1 -0.2385417          basal
#> Patient_2 -0.4403292   unclassified
#> Patient_3  0.8006550          basal
#> Patient_4 -0.4500838   unclassified
#> Patient_5  0.8175287          basal
#> Patient_6 -0.6076389   unclassified
```
