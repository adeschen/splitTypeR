# Draw a specific number of values from the normal distribution associated with each sample and each gene signature

This function establishes a sample-specific normal distribution for each
gene signature. For each sample, the actual GSVA score is used as the
mean of the normal distribution. The standard deviation is calculated
from the permutation results. The function returns a user-defined number
of values sampled from each sample-specific normal distribution.

## Usage

``` r
extractFromNormalDist(geneLists, gsvaRes, gsvaSD, nbValues)
```

## Arguments

- geneLists:

  a `list` containing signature gene lists.

- gsvaRes:

  a `matrix` as generated by the GSVA function. The `matrix` should
  contain the GSVA score for all the samples (column) and the signatures
  (row).

- gsvaSD:

  a `list` containing one entry per gene signature. Each entry contains
  a `vector` of the standard deviations for each sample as calculated
  from the permutations.

- nbValues:

  a `integer` superior or egal to 2 representing the number of values
  sampled.

## Value

a `list` containing one entry for each gene signature present in the
`geneLists` object. Each entry contains a `matrix` with all the values
sampled from the normal distribution obtained from the GSVA score (mean)
and the permutations (standard deviation). The rows correspond to the
samples, while the columns correspond to the number of draws.

## Examples

``` r

## Required library
library(GSVA)

## Load signatures
data(signaturesDemo)

## Create a list of two signatures
geneLists <- list()
geneLists[["classical"]] <- 
    signaturesDemo$`Classical`
geneLists[["basal"]] <- 
    signaturesDemo$`Basal-like`

## Load demo normalized expected counts
data(expNormalCountsDemo)

## Fix seed for reproducibility
set.seed(144)

## Calculate the real GSVA values
gsvaParameter <- gsvaParam(exprData=as.matrix(expNormalCountsDemo), 
     geneSets=geneLists)
resGSVA <- GSVA::gsva(param=gsvaParameter, verbose=FALSE)

## Calculate standard deviation for each sample using the permutation method
permResult <- splitTypeR:::permuteGSVA(geneLists=geneLists, 
    countMatrix=expNormalCountsDemo, permRatio=0.75, permNbr=20)

## For each signature, randomly extract values from the normal 
## distribution for each sample
normResult <- splitTypeR:::extractFromNormalDist(geneLists=geneLists, 
    gsvaRes=resGSVA, gsvaSD=permResult$SD, nbValues=10)
## For the classical signature, the sampled values for the first 3 patients
head(normResult$classical[1:3, ])
```
